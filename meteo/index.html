Le projet

Météo Villes présente chaque jour la météo de cinq villes — Rueil-Malmaison, Granville, Servon (50170), Rennes et Casablanca — pour le jour même et les 15 jours suivants, ainsi qu’un historique construit sur la plus longue période disponible. Le dashboard est régénéré automatiquement chaque jour.

Méthodologie
  • Prévisions (jour même + 15 jours) : API forecast d’Open-Meteo, complétée par 7 jours récemment observés (paramètre past_days) pour raccorder l’historique aux prévisions sans trou.
  • Historique : API archive d’Open-Meteo (réanalyses ERA5), depuis le 01/01/1940.
  • Ressenti (chaleur ressentie) : indice « température apparente » d’Open-Meteo, qui combine température, humidité et vent.
  • Humidité quotidienne : Open-Meteo ne fournit pas d’agrégat quotidien natif ; elle est calculée ici (moyenne, min, max) à partir de la série horaire.
  • Normale saisonnière et anomalie : moyenne des températures observées le même jour de l’année (± 7 jours, toutes les années depuis 1940), comparée à la prévision du jour.
  • Coordonnées des villes : latitude/longitude fixées à l’avance (villes.csv) plutôt qu’un géocodage par nom, pour éviter toute ambiguïté (plusieurs communes françaises portent le même nom — le code postal 50170 désigne sans ambiguïté le Servon de la Manche).

Limites à garder en tête : les réanalyses ERA5 ont une résolution spatiale d’environ 9 km (une valeur unique pour toute une zone, pas une station précise) ; l’incertitude des prévisions croît avec l’horizon, les jours 10 à 15 étant surtout indicatifs d’une tendance.
